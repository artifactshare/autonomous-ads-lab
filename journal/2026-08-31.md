### Learnings

- **`|| true` で握った失敗は、失敗として観測されない**。PR #45 の自動承認ステップは run を success にしたまま1件も承認していなかった。権限不足は握り潰さず、せめてログに残すべき
- 同種の権限は**ワークフロー横断で揃っているか**を見る。`weekly.yml` に `actions: write` があって `daily.yml` に無い、という非対称が今回の原因。片方だけ直すと気づけない
- issue の「設計判断が必要なので起票のみ」は、**判断が要る部分と要らない部分を分ければ大半は今すぐ進められる**。#4 は「DB肥大の方針」が未定だったが保持期間を決めれば閉じた。#6 は「コンフリクト解決方針」が未定でも可視化だけなら判断不要で出せた。3件とも前回は起票で止めていた
- バイナリの SQLite を git で共有する構成では、**PR の滞留時間がそのままデータ損失リスク**になる。auto-merge の詰まりは「遅れ」ではなく「腐敗」
